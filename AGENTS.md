# Работа над проектом

- Читать README.md и docs/architecture.md. При изменении запуска проверять scripts/start.mjs на чистой копии.
- Канал — реальная ветка Двача: корень, категория, доска или тред. Подборка — объединение выбранных веток. Не добавлять свою классификацию. По запросу пользователя от 13 сентября добавлена локальная персонализация по просмотрам: сохранять выбор источников, долю исследования и возможность отключения/сброса.
- На всех уровнях дерева — категории, доски, треды — сортировать по убыванию показанного количества видео. При равенстве — название. Не закреплять отдельные категории в конце.
- Нажатие на название включает эфир; раскрытие не переключает видео.
- Собирать вложения всех постов, обрабатывать files: null, сохранять ссылку на исходный пост. Не выдавать OP-вложения каталога за полный набор видео.
- По умолчанию показывать ветки с найденными видео; полный реестр доступен через «Все доски». Пока приложение открыто, постепенно пополнять постоянный индекс метаданных. Задача выбранного эфира отменяется при смене источника. Не скачивать видеоархив.
- Проверять плеер в реальном браузере. HTTP 200/206 недостаточно. Смена канала не должна принимать устаревшие ответы.
- После изменений: npm test и npm run build. Проверять релевантный пользовательский путь в браузере.
- Сохранять чужие изменения. Не публиковать приложение без соответствующего запроса.

- Фильтр длительности применяется к счётчикам и образцам видео на всех уровнях дерева, не только к очереди. При активном фильтре скрывать ветки без подходящих видео даже в режиме «Все доски»; сохранять раскрытие при смене порога.
